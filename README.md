# My Town Board (React)
1. Install Node.js LTS from https://nodejs.org
2. In a terminal inside this folder (the one containing package.json): `npm install`
3. `npm run dev` and open http://localhost:5173
Production build: `npm run build` then `npm run preview`.
Routes: `/`, `/city/atlanta|savannah|suwanee`, `/signup`, `/guidelines`, `/privacy`. Data persists in localStorage.
